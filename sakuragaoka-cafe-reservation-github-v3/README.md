# 桜丘カフェ｜予約サイト 提案用プレビュー

2026-11-20時点の提案用デモ。HTML / CSS / JavaScript だけで動作します。Node.jsのインストールやビルドは不要です。

## ローカルで試す
`index.html` をブラウザで開いてください。写真は `assets/birthday-plate.jpg` にあります。

## GitHub Pagesに公開する
1. GitHub上で **新しいリポジトリ**（例: `sakuragaoka-cafe-reservation`）を作成します。既存の別プロジェクトにはアップロードしないでください。
2. このフォルダの **中身**（`index.html`, `assets`, `.nojekyll`, `README.md`）をリポジトリのルートにアップロードして `Commit changes` を押します。ZIP自体はアップロードしないでください。
3. リポジトリの **Settings → Pages → Build and deployment → Source: Deploy from a branch** を選択します。
4. **Branch: main / (root)** を選び **Save**。公開URLは通常 `https://<GitHubユーザー名>.github.io/<リポジトリ名>/` です（環境により異なります）。
5. 実際にページを開き、バースデープレート写真が表示され、予約の種類と入力画面が切り替わるか確認してください。

## Vercelを使う場合
Vercelの `Add New → Project` からGitHubのリポジトリをImportし、静的サイトとしてデプロイ可能です。プレビュー段階ではGitHub Pagesだけで十分です。

## 注意 / 未実装
- お客様の予約は **保存・送信されません**。メールも **実際には送られません**。
- 8組上限やテーブル数の制限、空席状況、キャンセル処理は **サーバー側で未実装** です。
- Googleカレンダー連携は **未実装** です。
- 予約フォームに入力した名前・電話番号・メールアドレスは、このデモではブラウザ内の表示だけに使用し、送信しません。
- **提案・動作確認用URLをお客様向けの予約リンクとして掲載しないでください。** 誤予約の原因になります。
- 本番公開前に、予約確定の運用、最終受付時刻（22:00）、席の2時間制の条件、キャンセル料を店長に確認してください。
- 写真の掲載権限を確認した上で利用してください。
