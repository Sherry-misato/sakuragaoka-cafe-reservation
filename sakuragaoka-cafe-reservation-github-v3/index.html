ご予約に関する注意事項

ご予約前に必ずご確認ください。

  1. ご予約時間から15分以上遅れる場合は、必ず店舗までご連絡をお願いいたします。
  2. 混雑時は、お席のご利用を2時間制とさせていただきます。
  3. 座席のご希望は、当日の状況によってご希望に添えない場合がございます。
  4. アレルギーをお持ちのお客様は、必ず事前にご記入ください。
  5. 当日キャンセルの場合は、ご予約料金の100％をキャンセル料として頂戴いたします。
  6. バースデープレートをご注文のお客様は、提供のタイミングについてスタッフにお声がけいただきますよう、ご協力をお願いいたします。
  7. ご予約フォーム送信後、店舗からの確認連絡をもって予約確定となります。
  8. 16:00以降にご来店のお客様は、お一人様につき1ドリンク以上のご注文をお願いいたします。

皆様に快適にお過ごしいただけるよう、ご理解とご協力をお願いいたします。

・ご予約はご来店日の前日まで承ります。
・同時にご利用いただけるのは最大8組です。
・5名席は1卓、6名席は2卓（6名以上の予約は電話受付）。
・22:00開始枠は店舗の最終確認が必要です。
